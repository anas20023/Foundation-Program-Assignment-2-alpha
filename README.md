# 🎬 MovieExplorer

A responsive movie/show discovery application built with React. Users can browse shows, search by title, and view detailed information in an interactive modal.

## ✨ Features

- 🎥 Cinematic and responsive homepage
- 🔎 Search movies/shows by title
- 🎬 Browse shows from TVMaze API
- ⭐ Display ratings and release year
- 🖼️ Movie/show poster cards
- 📋 Detailed information modal
- 📱 Fully responsive design
- ⌨️ Escape key and outside-click modal closing
- ⏳ Loading, error, and empty states
- 📱 Responsive mobile navigation

## 🛠️ Tech Stack

- React 19
- JavaScript
- Vite
- Tailwind CSS 4
- HeroUI
- React Router
- Axios
- Lucide React
- TVMaze API
